Publish to web turns a public drive, a folder, or a single file into a web page with a link you can share. You can also publish a file by itself, with no page around it.

A published page is public and permanent. Anyone with the link can open it, and search engines can list its files. You can't unpublish a page, so publish only what you want everyone to see.

## Before you start

- A drive must be public to publish it, and so must a folder. A file in a private drive can have a file page that opens only with the key in its link.
- Hidden items in a public drive can still be found, because the data is public. ArDrive leaves hidden items out of the page.
- ArDrive can't publish a drive, folder, or file that has changes it hasn't confirmed on Arweave. The message says you can publish once they are confirmed, usually within an hour.

## Publish a drive

1. Open a public drive.
2. Click the menu at the right of the drive name, and click **Publish to web**.

   ![A drive menu with Share drive, Publish to web, and other items](/help/3-0/publish-menu.png)

3. In **What's included**, check the number of files and folders. Click **Next**.

   ![Step 1 of 3, What's included, showing file and folder counts](/help/3-0/publish-included.png)

4. In **How it looks**, enter a **Title**. Optional: add a **Description**, a **Cover**, or an **Icon**. The **Page** and **Link preview** panels show the result. Click **Next**.

   ![Step 2 of 3, How it looks, with the title, description, and previews](/help/3-0/publish-look.png)

5. In **Review and publish**, check **What**, **Title**, and **Link**.

   ![Step 3 of 3, Review and publish, with the cost](/help/3-0/publish-review.png)

6. Optional: open **Give it a name like yours.ar.io** to point a name you own at the page. Buy and renew names in the ar.io Console.

7. Click **Publish**. Keep the tab open until ArDrive finishes.

When it finishes, **Your page is published** shows the link. Click **Copy link** to copy it, or **Open page** to see it. The first time, a page can take a minute to load.

## Publish a folder

1. Open the folder's menu in the drive, and click **Publish to web**.
2. Follow steps 3 to 7 of [Publish a drive](#publish-a-drive).

The page holds the folder and everything in it. ArDrive can't publish a folder that is hidden or inside a hidden folder. Unhide it first.

## Publish a file

1. Open the file's menu, and click **Publish to web**.
2. In **How to publish**, choose one, then click **Next**.

   - **File page.** A page for this file, with a title, description, and preview.
   - **The file itself.** The file at a permanent link, with a name if you like. Available for files in public drives.

   If **File page** shows "Available after the next ArDrive release.", file pages aren't offered. A public file is then published as the file itself.

   ![How to publish, with File page and The file itself](/help/3-0/publish-file-how.png)

3. In **How it looks**, enter a **Title**. Click **Next**.
4. In **Review and publish**, click **Publish**.

For a private file, a file page opens the file only with the key in its link. Anyone with that link can open the file, and the key opens every version of it. The title, description, and images are public.

## Cost

The review shows the cost. A small publish shows **Cost: 0 credits** and says that uploads this small are free with Turbo. A larger one costs Turbo Credits or AR. If you can't cover it, ArDrive says so. See [Add Turbo Credits and use Billing](/help/using-ardrive-apps-using-ardrive-add-turbo-credits-and-billing).

When you pay with AR, the page opens 15 to 30 minutes after you publish, once the network confirms it.

## Find your web pages

The **Web pages** list in the sidebar shows everything you have published, with its link and the date you last updated it.

1. Click **Web pages** in the sidebar.
2. Click the menu at the right of a page to **Open page**, **Copy link**, **Update page**, **Add name**, or **Open folder**.

![The Web pages list with a page menu](/help/3-0/web-pages-menu.png)

To publish from this list, click **Publish**, choose a drive, open a folder if you want one, and click **Publish drive**, **Publish folder**, or **Publish file**. Select a file in the list to publish only that file.

![The publish picker inside a folder, with Publish folder](/help/3-0/publish-picker.png)

## Update a page

After you change the files, update the page to show them.

1. Click **Web pages** in the sidebar.
2. Open the page's menu and click **Update page**.
3. In **Published to web**, click **Update** and follow the steps.

![The Published to web dialog with Update, Open page, and Done](/help/3-0/publish-update.png)

An update gets a new link. Earlier links keep working. If a name points at the page, it moves to the new link.

## If publishing stops

- **Publishing didn't finish.** Click **Try again**. If a transaction already reached the network, ArDrive tells you it is paid for.
- **Publishing stopped.** Open **Publish to web** and try again.
- **There's nothing to publish here yet.** The drive or folder has no files that visitors could see.
