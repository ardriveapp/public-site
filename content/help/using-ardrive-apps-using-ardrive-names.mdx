A name is a web address you choose, such as maya.ar.io, for a published page, a deployment, or a public file. ArDrive calls these ArNS names. You can point a name you own at your content and change what it points to later.

ArDrive doesn't sell names. Buy and renew names in the ar.io Console. ArDrive assigns a name you already own, and you pay for the change with Turbo Credits.

## What you can name

- A published page: a drive, a folder, or a file. See [Publish to web](/help/using-ardrive-apps-using-ardrive-publish-to-web).
- A deployment. See [Create a deployment](/help/using-ardrive-apps-using-ardrive-create-an-arweave-manifest).
- A public file.

A private file can't have a name. To name a folder or a site, publish it to the web first.

## Link your Solana wallet

ArNS names are owned by Solana wallets, so ArDrive needs to know which wallet holds yours. You link it once.

1. Click **Names** in the sidebar.
2. Click **Link a Solana wallet**.
3. Approve in your wallet.

You can also click **Link** next to **Solana, for names** on [Account and security](/help/using-ardrive-apps-using-ardrive-account-and-security).

If ArDrive says **No Solana wallet found**, open ArDrive in your wallet's app, or install Phantom or Solflare. The message has links for each.

![Link a Solana wallet, with No Solana wallet found](/help/3-0/names-link-wallet.png)

If you sign in with Phantom or Solflare, that wallet is already the wallet for names. There is nothing to link.

Your linked wallet approves name changes. Turbo Credits pay for them, with one exception: if you manage a name for its owner, your ArNS wallet pays the network fee in SOL instead of credits.

## See your names

**Names** lists every name your linked wallet holds, with what each points to. If the wallet holds no names, the page says **No names yet** and links to the ar.io Console, where you can get one.

## Give a page a name

You can start from any of these places:

- A published page: click **Add name** in its menu in [Web pages](/help/using-ardrive-apps-using-ardrive-web-pages).
- A public file: open its **Details** tab from **More info**, and click **Add name** next to **Name**. A pinned file also has **Add name** in its menu.
- While you publish or create a deployment: open **Give it a name like yours.ar.io** in the review.

Then:

1. Choose the name. ArDrive says "Choose a name for" and the item.
2. Optional: add an undername, such as blog for blog_maya.ar.io. Use letters, numbers, - and _, and start with a letter or number.
3. Check the **Cost**. ArDrive shows it, in Turbo Credits or in SOL, before your wallet is asked.
4. Confirm the change.
5. Approve in your wallet when it asks. It can ask twice. ArDrive says **Approve once more in your ArNS wallet** for the second request.

ArDrive says **Name saved** when it finishes, and says how soon the name goes live. Gateways keep an old answer for a short time, called the cache time. A shorter cache time shows changes sooner, and a longer one loads faster for visitors.

## Change or remove a name

- To point a name at something else, click **Change name** in the item's menu, or choose **Change what it points to**.
- To remove a name, click **Remove name**.
  - An undername stops working.
  - A main name keeps working. It shows a page that tells visitors nothing is here right now, so links to it keep working.

If you hide a file that has a name, the name still opens it. ArDrive asks **Remove its name too?** so you can remove it.

## If a change doesn't go through

ArDrive says what happened and whether you were charged:

- **Not enough credits.** Add Turbo Credits and try again. Nothing was charged. See [Add Turbo Credits and use Billing](/help/using-ardrive-apps-using-ardrive-add-turbo-credits-and-billing).
- **It wasn't approved in your wallet.** Nothing was charged.
- **The change wasn't approved in time.** Your credits come back within 15 minutes.

## Renew a name

Names are leased. ArDrive shows when a lease ends. Renew the name in the ar.io Console to keep it.
