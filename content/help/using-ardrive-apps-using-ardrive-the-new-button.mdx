**New** is the red button at the top left of ArDrive. It makes things. Everything you can add to your drives starts here.

![The New menu, with Advanced open to New deployment, New snapshot, and Import from manifest](/help/3-0/new-menu.png)

The menu has these items:

- **Upload files.** See [Uploading files](/help/using-ardrive-apps-using-ardrive-uploading-files).
- **Upload folder.** Uploads a folder from your computer with everything in it.
- **New folder.** See [New folders](/help/using-ardrive-apps-using-ardrive-new-folders).
- **New note.** Writes a text note in the open folder.
- **New file pin.** Adds a file that is already on Arweave. See [Pin a file](/help/using-ardrive-apps-using-ardrive-pin-a-file).
- **New drive.** See [Create a drive](/help/using-ardrive-apps-using-ardrive-create-new-drive).
- **Attach drive.** Adds a drive someone shared with you. See [Attach a drive](/help/using-ardrive-apps-using-ardrive-attach-a-drive).
- **Advanced.** Opens more items:
  - **New deployment.** In a public drive only. See [Create a deployment](/help/using-ardrive-apps-using-ardrive-create-an-arweave-manifest).
  - **New snapshot.** See [Create a snapshot](/help/using-ardrive-apps-using-ardrive-create-a-snapshot).
  - **Import from manifest.** In a public drive only. Adds the files that an existing manifest lists to the drive.

The menu shows what fits where you are. On **Your drives**, with no drive open, it has **Upload files**, **Upload folder**, **New drive**, and **Attach drive**. **Upload files** and **Upload folder** are dimmed there until you open a drive. Inside a private drive, **Advanced** has only **New snapshot**.

**New** only makes things. To change something that exists, such as to share, rename, move, or hide it, use the item's own menu. See [Actions](/help/using-ardrive-apps-actions-actions).
