A pin adds a file that is already on Arweave to your drive. ArDrive saves a small record that points to the file's data. It doesn't upload the data again, so the pin shows the size of the original file.

Use a pin to keep a file you found on Arweave, or one you uploaded somewhere else, with the rest of your files.

## Pin a file

1. Open the drive and the folder where the pin should go.
2. Click **New**, then click **New file pin**.
3. In **Enter transaction ID or file ID**, paste the transaction ID of the data, or an ArDrive file ID.
4. In **Enter file name**, type the name the file should have in your drive.
5. Click **Create pin**.

![The New file pin dialog with the transaction ID and file name fields](/help/3-0/new-file-pin.png)

The pin appears in the folder at once. Its status dot is pending until the network confirms the record. A small circle with a pin icon at the right of the row marks it as a pin.

![A folder with pinned files, each with a pin icon](/help/3-0/pinned-files.png)

A pin is a small write, so it counts toward your free upload allowance, or uses Turbo Credits. If it fails, ArDrive says "Your pin failed to upload".

## Use a pinned file

A pinned file has most of the same actions as a file you uploaded. Click the menu at the right of its row for **Preview**, **Share file**, **Add name**, **Download**, **Rename**, **Move**, and **Hide**. While the record is pending, the menu also has **Check upload status**.

A pinned web page can show in [Web pages](/help/using-ardrive-apps-using-ardrive-web-pages), labelled **pinned in** and the name of the drive.

## What a pin doesn't do

- A pin doesn't copy or change the data. The data stays at its own transaction ID.
- A pin points to data that is already public on Arweave. Pin only data you are happy to show in your drive.
- Hiding a pin removes it from the view of your drive. The data stays on Arweave.
