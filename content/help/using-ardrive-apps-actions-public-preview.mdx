Every file in a public drive has a web address. You can search it, share it, and open it like any other web address.

1. Click the menu at the right of the file, and click **Preview**.
2. A new tab opens with the file. ArDrive can show files your browser can display, such as photos, music, video, and PDFs.

You can also open the details panel with **More info**. The preview icon in its toolbar does the same, and the **Preview** tab shows the file inside ArDrive.

Private files have no **Preview** item.

## Web addresses on the permaweb

When you preview a file, the new tab shows your data on the permaweb. The first part of the address is a sandbox that the gateway uses. The string after the gateway name is the data item's transaction ID.

You can share the address, embed it on a website, or bookmark it as a record of your public files.

If your browser can't display a file type, it downloads the file instead.
