**Web pages** lists everything you published to the web: drives, folders, and files. Use it to open a page, copy its link, update it after you change the files, and give it a name.

To make a page, see [Publish to web](/help/using-ardrive-apps-using-ardrive-publish-to-web).

## Open Web pages

Click **Web pages** in the sidebar. Opening it folds the drive lists in the sidebar. Click **Your drives** to go back.

The list has three columns:

- **Page.** The page name, with the drive it belongs to under it. A file you pinned shows **pinned in** and the drive name.
- **Link.** A short form of the page link.
- **Updated.** The date of the last update. The newest page is first.

![The Web pages list with each page's link hidden](/help/3-0/web-pages-list.png)

If you haven't published anything, the page says **Nothing published yet** and has a **Go to your drives** button.

![Web pages with nothing published](/help/3-0/web-pages-empty.png)

## Use a page

Click the menu at the right of a row. The menu has these items:

| Item | What it does |
|---|---|
| **Open page** | Opens the page in a new tab. |
| **Copy link** | Copies the page link. |
| **Update page** | Publishes the page again with your latest changes. A drive, folder, or file page has this item. |
| **Add name** | Points a name you own at the page. See [Names](/help/using-ardrive-apps-using-ardrive-names). |
| **Open folder** | Opens the drive or folder the page comes from. |

A pinned file page has no **Update page** item.

## Publish from this page

Click **Publish**, choose a drive, and follow the steps in [Publish to web](/help/using-ardrive-apps-using-ardrive-publish-to-web). ArDrive asks which drive first.

## Update a page

An update gets a new link. Earlier links keep working. If a name points at the page, it moves to the new link. The steps are in [Publish to web](/help/using-ardrive-apps-using-ardrive-publish-to-web#update-a-page).

## Pages are public

Anyone with a page link can open the page. Publishing can't be undone. Hide a file in your drive to leave it out of the next update. Hiding doesn't remove data that is already public.
