A deployment publishes a folder at one Arweave address, with each file at a friendly path. ArDrive stores it as an Arweave manifest.

An Arweave manifest maps file names and paths to Arweave transaction IDs. A gateway reads it, so you can open files by name:

```text
https://turbo-gateway.com/MANIFEST_TX_ID/index.html
https://turbo-gateway.com/MANIFEST_TX_ID/images/logo.png
```

Replace MANIFEST_TX_ID with the transaction ID of the deployment.

Without a manifest, each file has its own address made of its transaction ID. For how manifests work, see [Arweave Manifests](/help/understanding-the-permaweb-general-arweave-manifests).

To publish a drive, a folder, or a single file as a web page, use [Publish to web](/help/using-ardrive-apps-using-ardrive-publish-to-web). Use a deployment when you want a website or an app at one address, for example one that you also name with [Names](/help/using-ardrive-apps-using-ardrive-names).

## Create a deployment

You can create a deployment only in a public drive.

1. Open the public drive.
2. Click **New**, click **Advanced**, and click **New deployment**.
3. In **Target folder**, open the folder to publish. Stay at the top to use the whole drive. The deployment includes every file in the folder and its subfolders.

   ![Target folder, listing the folders in the drive, with a fallback page field](/help/3-0/deployment-target.png)

4. Optional: enter a **Fallback page**. This is the transaction ID of the file that opens when a path isn't found.
5. Click **Next**.
6. In **Deployment name**, enter a name for the deployment, then click **Next**.

   ![New deployment, with the deployment name field](/help/3-0/new-deployment.png)

7. Review the deployment. ArDrive shows its size and its cost. A small deployment shows **Cost: 0 credits** and says that uploads this small are free with Turbo. A larger one costs Turbo Credits.
8. Optional: open **Give it a name like yours.ar.io** to point a name you own at it. See [Names](/help/using-ardrive-apps-using-ardrive-names).
9. Click **Create deployment**.

ArDrive leaves hidden files and folders out of the deployment. The review warns that files uploaded here are viewable by anyone on the internet, so publish only what you want everyone to see.

If some files in the folder are still pending, ArDrive says **Files pending** and recommends that you wait until they confirm.

The deployment appears in your drive as a file of type **Deployment**.

## Open a deployment

Open the link of the deployment to see its default page. A deployment opens `index.html` if it has one. If it has none, the first file in the deployment opens, and all other files stay reachable by their paths.

To check the paths a deployment uses, open its raw manifest in your browser at `turbo-gateway.com/raw/MANIFEST_TX_ID`.

## Update a deployment

After you change the files, create a deployment again with the same name. ArDrive adds a new version of the deployment with the new transaction IDs. Earlier versions stay on Arweave.

## Import files from a manifest

**New**, **Advanced**, **Import from manifest** adds the files that an existing manifest lists to your drive.

## Customize a manifest

The ArDrive CLI can create a manifest from a public drive or folder and export a preview. You can edit the preview, for example to add transaction IDs that aren't in your drive, and upload it with the CLI. See the [docs portal](https://docs.ardrive.io).
