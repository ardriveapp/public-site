---
title: "Move A File Or Folder"
description: "Move files or folders to another folder in the same drive."
category: "Using ArDrive Apps"
section: "Actions"
---

Move a file or a folder to another folder in the same drive.

1. Click the menu at the right of the file or folder, and click **Move**.
2. In **Move items**, find the destination. Click a folder's arrow to open it.
3. Optional: click **Create folder** to make a new folder here.
4. Click **Move here**.

![The Move items dialog with the drive's folders, Create folder, and Move here](/help/3-0/move-items.png)

You can also open the details panel with **More info**. The move icon in its toolbar does the same.

Files and folders can't move from one drive to another.

Moving is a small write. When your free upload allowance covers it, it costs nothing. Otherwise it uses Turbo Credits.
